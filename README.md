# Deforestation Risk Zoning in Atewa Forest Range, Ghana

Research Question:
Which zones in Atewa Forest Range have the highest deforestation risk due to illegal mining (galamsey) and agricultural expansion?

This project was built as part of My GeoDev Lab Africa Cohort One - a 12-month applied GIS program.

Tools:
QGIS 3.34, Google Earth Engine, Sentinel-2 (10m), SRTM DEM 30m

Key Result: Map showing High/Medium/Low deforestation risk zones + area in hectares lost (2020-2024)

Author:Joshua | Geography Graduate, University of Ghana | Aspiring Geospatial Data Scientist | Future Tropical Forester

Data Sources:
Copernicus Sentinel-2, USGS SRTM, Protected Planet (WDPA), OpenStreetMap
